# Project Dashboard 詳細規則

[回到教學](../README.zh-TW.md) · [English details](details.md)

## 檔名與日期

儀表板只讀 `Project folder` 裡直接存放的 Markdown 筆記，預設資料夾是 `Projects`。不讀子資料夾。名稱包含 `Projects to skip` 任一片段的筆記會略過。資料夾不存在時，會顯示 `找不到專案資料夾：<folder>`。一則筆記讀取失敗時會略過它，其他專案照常顯示。

檔名可以寫成 `🚧 P-20261102 範例專案.md`。`P-` 可以省略。外掛在檔名前 3 個 Unicode 字元裡找狀態符號：

| 符號 | 畫面標籤 | 意思 |
| --- | --- | --- |
| `🚧` 或沒有符號 | `🚧 進行中` | 正在推進 |
| `⏳` | `⏳ 暫停` | 暫時不推進 |
| `✅` | `✅ 完成` | 已完成 |
| `❌` | `❌ 取消` | 已取消 |

筆記最上方的屬性欄位使用這些名稱：

| 欄位 | 用途 |
| --- | --- |
| `開始日期` | 專案的開始日期 |
| `預計結束日期` | 專案的預計結束日期，優先用來決定迄日 |
| `實際結束日期` | 讀不到預計結束日期時，改用這個迄日 |

日期用 `YYYY-MM-DD`。缺少起日或迄日時，會嘗試從檔名推算。例如 `P-20261102 ~ 1218 範例專案` 的起日是 `2026-11-02`，迄日是 `2026-12-18`。後面的日期也可以寫成 `20261218` 這樣的 8 位數。只有一個 8 位數日期時，檔名會提供相同的起訖日。frontmatter 裡的日期優先於檔名。

如果迄日仍然缺少，而且起日不晚於今年 12/31，就用今年 12/31 作為迄日。切到其他年份不會改變這個預設。起日沒有預設值。一般專案列需要同時有起日與迄日。

滑過專案名稱旁的 `⚠` 可以看原因。例如 `起日由檔名推得`、`迄日由檔名推得`、`迄日預設為 <year>-12-31`、`缺開始日期` 或 `缺預計結束日期`。

很遠的日期也不能拖累其他列，例如迄日寫成 9999 年。如果某列畫不出來，只有那列的週格子留白並顯示 `⚠`。提示寫 `這個專案的日期有問題`，其他列照畫。

## 任務日期

任務日期寫成 `📅` 或 `✅`，後面接空白與 `YYYY-MM-DD`。`📅` 表示預計，`✅` 表示完成。單獨的日期、斜線日期與 `due: 2026-11-20` 都不算。同一行所有符合的日期都會算，包含預計日期與完成日期。

- 核取方塊是 `[x]`、`[X]`，或有 `✅ YYYY-MM-DD` 標記時，該任務算完成。同一個任務的所有日期都沿用這個完成狀態。
- `[[✅ P-2026 範例專案]]` 這種連結裡的 `✅` 不會讓任務變成完成。
- 日期依 ISO 週對應，每週從星期一到星期日。星期五永遠算在自己的那一週。
- `Saturday tasks count for next week` 預設關閉。開啟時，週六任務算到下一個星期一的那週。星期日任務與行事曆行程不受影響。

| 任務日期 | 週六設定關閉 | 週六設定開啟 |
| --- | --- | --- |
| `2026-10-30`（五） | `2026-W44` | `2026-W44` |
| `2026-10-31`（六） | `2026-W44` | `2026-W45` |
| `2026-11-01`（日） | `2026-W44` | `2026-W44` |
| `2027-01-02`（六） | `2026-W53` | `2027-W01` |

任務日期決定哪些週有工作，不會自動改寫專案的預計結束日期。專案顯示時，有日期的任務一律出現在它那一週。開始日期之前、結束日期之後也一樣。同一任務有跨週日期時，可以出現在不同週，但每週只列一次。

## 年視圖

年視圖從今天的本地年份開始。欄位包含星期四落在顯示年份的所有 ISO 週，2026 年有 53 週，2027 年有 52 週。今天所在週屬於顯示年份時，該欄才有淡紅色底。

年份旁的 `◀`、`▶` 一次切換一年。翻到其他年份才出現 `今年`，按下回到今年。只有年視圖或月視圖的選擇會被記住，上次看的年份不會。

逐週模式每格各自判斷：

| 這週有任務嗎 | 專案與日期條件 | 格子樣式 |
| --- | --- | --- |
| 有 | 進行中或暫停，週一在迄日當天或之後 | 紅色超出期限格 |
| 有 | 進行中或暫停的其他週，包含開始日期之前 | 分類色實心，全部完成時是淡色加 `✓` |
| 有 | 已完成或取消 | 實心並套用已結案的灰色樣式 |
| 無 | 進行中或暫停，這週碰到專案期間 | 虛線 |
| 無 | 其他情況 | 空白 |

專案期間含起日、不含迄日。那一週只要碰到迄日前的專案期間，就算有重疊。紅色以週一判斷，因此任務剛超出迄日、卻仍在同一週時，格子可能仍是分類色。紅色優先於全部完成的淡色樣式。

例如預計結束日期是 `2026-11-06`，另有任務排在 `2026-12-05`。開啟週六設定時，任務出現在 `2026-W50` 並標紅色。那格能打開浮窗，12 月的月視圖也會列出任務。中間沒有任務的週仍留白。開始日期之前的任務也會出現。勾選 `顯示已結案` 後，已結案專案在迄日之後的任務用灰色實心顯示。

進行中或暫停的專案沒有任務日期時，年視圖會在專案期間畫一整條虛線。點哪一週就打開哪週的浮窗。月視圖則分成每週一個虛線格。

按 `T` 切到 **Timeline**，每個專案是一條連續的分類色色條。左端取起日那週與第一個任務週較早的那週，右端取迄日那週與最後任務週較晚的那週。只畫顯示年份內的部分。色條沒有空週缺口或紅色超出期限段，已結案仍用灰色。點 Timeline 色條只顯示文字，沒有編輯控制。在月視圖按 `T` 沒有作用，也不會重新讀取筆記或行事曆。

## 週浮窗與編輯

點實心、淡色、紅色或虛線的週格子，可以打開可編輯的浮窗。空白格不會打開。標頭有專案名稱、週次與週一到週日的日期。超出期限的週會加上 `⚠ 已超出預計結束日期 <end>`。空週顯示 `這週還沒有任務`。

只要某行有日期對應到這週，就會列入。每一行最多列一次。先依該行對應到這週的最早日期排序，再依筆記行序排列。月視圖用相同的清單與順序。顯示文字會拿掉項目符號、核取方塊與日期標記，裁掉 ` > ` 開始的部分，再合併多餘空白。

未完成任務顯示預計日期。已完成任務顯示 `已完成`，有完成日期時也會列出。從上週六算進來的任務會顯示 `預排在上週六，算進本週`。已完成則顯示 `上週六完成，算進本週`。

### 編輯動作

- **勾完成或取消**：勾選後變成 `[x]`。沒有完成標記時，補上 `✅ 今天日期`。取消勾選會變回 `[ ]` 並移除完成日期標記。今天依裝置本地日期判斷。
- **換週**：`◀`、`▶` 把第一個 `📅` 日期減少或增加 7 天，保留星期幾。只有未完成且有預計日期的核取方塊任務顯示這些按鈕。
- **挑未排日期的任務**：`＋ 從還沒排日期的任務挑一個（N）` 依筆記順序列出任務。點任務就補上預計日期。清單沒有任務時顯示 `這則筆記沒有還沒排日期的任務`。
- **新增任務**：`＋ 新增任務` 打開輸入框。按 Enter 後加入 `- [ ] <文字> 📅 <日期>`，放在最後一個核取方塊任務之後。沒有任務時放在筆記末尾。空白輸入不寫入，多餘空白與換行會合併。已經輸入 `📅 YYYY-MM-DD` 時保留該日期。中文輸入法選字的 Enter 不會送出。新增後輸入框維持開啟並清空，可以接著新增。輸入框裡按 Escape 只關閉輸入框。
- **跳到任務行**：`↗` 在右側打開筆記並選取該行，同時關閉浮窗。找不到行時仍會開啟筆記，並提示 `找不到那一行，可能剛被改過`。
- **開啟專案筆記**：點標頭的專案名稱，沿用右側筆記窗格。原本的格子仍看得到時，浮窗會留著。

新增或挑選任務使用 `Which day to write` 指定的星期，預設是星期五。如果選星期六又開著週六設定，就寫那週星期一之前的星期六。這樣任務仍會對應到選定的那週。

| 目標週 | 星期選擇 | 週六設定 | 寫入日期 |
| --- | --- | --- | --- |
| `2026-W45` | 星期五 | 開或關 | `2026-11-06` |
| `2026-W45` | 星期一 | 關 | `2026-11-02` |
| `2026-W45` | 星期六 | 關 | `2026-11-07` |
| `2026-W45` | 星期六 | 開 | `2026-10-31` |
| `2026-W45` | 星期日 | 開 | `2026-11-08` |

### 編輯限制與關閉方式

可編輯的核取方塊使用 `-`、`*` 或 `+`，後面接 `[ ]`、`[x]` 或 `[X]`。其他核取方塊狀態與沒有核取方塊的日期文字只能看。frontmatter 與程式碼區塊裡的範例不會修改。有 `🔁` 的重複任務要到筆記裡勾選，讓 Tasks 外掛處理下一次任務。

所有編輯都使用 Tasks 的日期符號格式。即使 Tasks 設成 Dataview 格式或關閉完成日期，仍然使用這個格式。行尾有 `^plan1` 這樣的區塊參照時，日期放在它前面。其他文字、各行換行方式與筆記內容都會保留。

修改前會檢查那行是否和上次讀到的相同。行的位置改變時，仍能尋找唯一相同的行。如果內容已變或無法確定是哪行，就不寫入並重新整理。提示是 `這一行在筆記裡剛被改過，畫面已更新，請再試一次`。筆記不存在時顯示 `找不到這則筆記`。儲存期間該行控制暫時停用。

同時最多只有一個浮窗。再點同一格、點外面、在文字輸入欄之外按 Escape、按 `↗` 或捲動表格都會關閉。捲動浮窗內清單或旁邊的筆記不會關閉。空間足夠時，浮窗留在儀表板窗格內。放不下時會以視窗範圍為準，長清單在浮窗內捲動。把儀表板移到另一個視窗時會先關閉浮窗，移好後可以照常點開。

## 月視圖

按 `年`／`月` 或 `M` 切換。月視圖與年視圖使用相同的專案列、排序、篩選、分類控制與專案欄寬。各週平分剩餘空間，長文字會換行，列高隨任務增加。

一週屬於它的**星期一**落在的那個月。唯一例外是 ISO 第 1 週，永遠算一月，即使週一還在去年 12 月。年視圖的月份與季度表頭也用相同規則。2026 年 10 月有 W41–W44，11 月有 W45–W49。

標題寫出年、月與週次，例如 `2026 年 11 月（W45–W49）`。`◀`、`▶` 切換月份，可以跨年。翻到其他月份才出現 `本月`，按下回到今天這週所屬的月份。

從今年的年視圖切過來時，顯示今天這週所屬的月份。從其他年份切過來時，顯示那年一月。切回年視圖時顯示該月的年份。打開分頁時從今年或今天這週所屬月份開始。換年份、月份或視圖會關閉浮窗，自動更新則保留正在看的期間。

所有有日期的任務都列在對應的週，包含開始日期之前與預計結束日期之後。空白格沒有任務文字。文字樣式如下：

- 灰字加 `✓`：已完成。
- 紅字：還沒完成，而且那一週在今天這週開始前就結束了。
- 一般文字：還沒完成，那週仍是本週或未來。

文字與底色表示不同資訊。紅字表示過去那週有未完成任務，紅色底表示任務超出專案預計結束日期。底色依年視圖的逐週規則判斷。點非空白的專案格子會打開完整可編輯的週浮窗，即使年視圖留在 Timeline 模式也一樣。

## 還沒排

`還沒排` 只計算沒有日期的未完成核取方塊任務。已完成、純文字與自訂核取方塊狀態不算。日期符號寫壞或使用變體的任務要先回筆記修正，不會再提供一次排日期的選項。連結裡有 `✅` 但沒有日期時，仍可排入。

點數字後，任務依筆記順序列出。每個任務有目前月份每週的按鈕與 `↗`。專案在那週的格子不是空白時就能選。否則按鈕變灰並提示 `不在專案期間`。專案期間外的週如果已經有日期任務，也可能可以選。排入時使用和週浮窗相同的日期、儲存格式與行內容檢查。

排好一個任務後，浮窗維持開啟並少一列。最後一個排完、專案被隱藏、換月份或換視圖時會關閉。數字留白的格子點了沒有反應。其他關閉方式與週浮窗相同。

## General 列與行事曆

只要至少一個行事曆設定過連結，月視圖就會在所有專案上方顯示 `General`。沒有符合條件的專案也會顯示這列。全部沒設定時就隱藏。新加的空白行事曆不讀取，也不回報錯誤。設定過連結但這台電腦沒有存值時，會回報缺少連結。

General 列只能看。週格子不會打開浮窗，點它會關閉原本開著的浮窗。`還沒排` 格子永遠留白。今天這週與其他列一樣有淡紅色底。年視圖不顯示行事曆行程。

### 行事曆連結與標籤

Google 與 iCloud 的操作步驟見 [教學的行事曆設定](../README.zh-TW.md#general-列行事曆)。這類連結能讓別人讀行事曆。如果 Google 私密網址外洩，請到該日曆設定重設，再把新連結貼進外掛。舊網址會失效。

連結去掉頭尾空白後，必須以 `https://` 或 `webcal://` 開頭。`webcal://` 會換成 `https://` 讀取，其餘保持原樣。連結存在 Obsidian 的密鑰儲存區，不寫入外掛資料、本機偏好、紀錄、通知、提示或儀表板文字。每台電腦都要貼一次。行事曆名稱與顏色可以跟著其他設定透過 Obsidian Sync 同步。

每筆行程前面有名稱標籤。沒有取名時，依清單位置使用 `行事曆 1`、`行事曆 2` 等。設定過顏色就用該顏色。否則依序循環使用藍色（`#4a7fd4`）、綠色（`#2f9e6e`）、橘色（`#e08a2c`）、紫色（`#8e5bd6`）、青色（`#1b9aaa`）與粉色（`#d6559e`）。預設色避開紅色，紅色留給逾期與超出預計結束日期的提醒。名稱與顏色存好就會更新，不會重新讀取行事曆。

### 行事曆讀取時機

只有五個時機：

1. 打開儀表板分頁。
2. 按 General 列的 `↻`。
3. 執行 `Project Dashboard: Refresh calendars`。
4. 在已設好的行事曆貼上新連結，沿用同一個儲存項目時會馬上重新讀取。
5. 設定過連結的行事曆清單或順序改變。這項檢查發生在設定存好、外部設定載入，或存檔失敗還原上次設定後。

改名稱或顏色不會讀取。沒有定時器。切年份、月份、按 `今年` 或 `本月`、切換視圖與修改筆記都不會讀取。

所有開著的儀表板共用結果。讀取中又要求讀取時，等這次結束後再用當時設定多讀一次。重新讀取時，只要原本週格子仍可開啟，週浮窗就會留著。結果只放記憶體。移除行事曆或更換儲存連結的項目後，下次讀取會丟掉它原本的結果。其他行事曆保留自己的結果。卸載時清除結果，晚到的回應與等待中的讀取都不處理。

### 行程與日期

日期與時間使用裝置本地時間。行事曆提供的時區與 UTC 時間會轉成本地時間，不明時區或沒有時區時當作本地時間。整天行程保留原日期。時間用 24 小時制。

| 行程類型 | 名稱標籤後的文字範例 |
| --- | --- |
| 同一天內有時間的行程 | `11/6（五）13:30 讀書會` |
| 一天的整天行程 | `11/11（三）休假` |
| 多天的整天行程 | `11/7（六）–11/9（一）研習營` |
| 有時間且跨日的行程 | `11/8（日）22:00–11/9（一）01:00 夜間維護` |

沒有標題時寫 `（沒有標題）`。行程會出現在它碰到的每一週。結束時間不包含在行程裡，所以剛好週一 00:00 結束的行程不算進新的一週。沒有結束時間時，先用持續時間推算。兩者都沒有時，有時間的行程在開始時結束，整天行程則持續一天。週六任務設定不會移動行事曆行程。

重複行程會展開成每次發生的行程。排除日期、移動或取消的某次行程都會套用，取消的行程不顯示。相同行程識別碼與開始時間只顯示一次，跨行事曆也一樣。同一週依開始日期排序。同一天先列整天行程，再依開始時間、行事曆順序與標題排序。

### 狀態與錯誤

這次執行期間還沒讀取前，`General` 下方的狀態留白。讀取中顯示 `讀取中…`，完成後顯示 `更新於 15:20` 這樣的最後讀完時間。失敗時接上 `・⚠ 1 個行事曆讀不到`，數字依實際失敗數量。滑過去會逐行列出 `<名稱>：<原因>`：

| 原因 | 意思 |
| --- | --- |
| `連結格式不對` | 儲存的連結沒有使用支援的開頭 |
| `這台裝置找不到連結` | 這台電腦沒有存該行事曆的連結 |
| `讀取失敗（HTTP 404）` | 伺服器回傳錯誤，數字依實際狀態顯示 |
| `連不上` | 請求失敗，例如沒有網路 |
| `內容看不懂` | 回應無法讀成 iCalendar 檔案 |
| `行事曆太大` | 回應超過 20 MB |

失敗的行事曆會保留這次外掛執行期間最後成功讀到的行程。從沒成功過就沒有行程。其他行事曆與所有專案列照常。重複行程有展開次數上限，每個行程最多檢查 100,000 次。每次尋找日期也有 200,000 個候選日期的上限，避免寫壞的規則卡住儀表板。

[連網說明](../README.zh-TW.md#連網說明) 與 [第三方程式碼](../README.zh-TW.md#第三方程式碼) 保留在 README。

## 手機週清單

打開儀表板分頁時，由 Obsidian 判斷裝置是不是手機。手機顯示週清單，電腦與平板維持年視圖與月視圖。分頁開著時，轉向、改變視窗大小或縮窄窗格都不會換版面；下次打開儀表板分頁才重新判斷。

### 顯示哪 4 週

第一週是今天本地日期所在的 ISO 週，從星期一到星期日。後面接著 3 週，跨年也照算。判斷今天是哪一週時不套週六規則，即使今天是星期六也一樣。例如今天是 `2026-11-20`，標題依序是：

- `本週 W47 11/16–11/22`
- `下週 W48 11/23–11/29`
- `W49 11/30–12/6`
- `W50 12/7–12/13`

今天是 `2026-12-30` 時，則是 `本週 W53 12/28–1/3`、`下週 W1 1/4–1/10`、`W2 1/11–1/17`、`W3 1/18–1/24`。不能翻看其他週，也不能調整顯示幾週。

任務歸週與月視圖相同，會套用週六規則。開啟時，日期為 `2026-11-28` 的任務算進 `W49 11/30–12/6`。同一專案內的任務順序與週浮窗相同。同一任務有跨週日期時，可以出現在對應的每一週，每週只列一次。每行顯示核取方塊、任務文字，有預計日期時以 `M/D` 顯示。長文字會換行。

專案順序與篩選沿用儀表板的列。不在專案資料夾內，或符合 `Projects to skip` 的筆記不列入。依一般日期補足規則處理後，專案仍須同時有起日與迄日。已完成與取消的專案在手機上永遠不顯示；暫停的專案只有勾選 `顯示暫停（n）` 才顯示。有暫停專案可顯示時才出現這個控制項，每次打開分頁都從未勾選開始。

每個專案組的開頭是分類色點與專案名稱。那週沒有任務的專案不列出。所有顯示中的專案在那週都沒有任務時，寫一行灰字 `這週沒有任務`。日期只落在第 4 週之後的任務不會出現。

以今天是 `2026-11-20`、週六規則關閉為例，`範例專案 A` 的未完成任務會出現在這些地方：

| 任務 | 預計日期 | 顯示位置 |
| --- | --- | --- |
| `寄出邀請` | `2026-11-06` | 展開後的 `之前還沒做` |
| `準備讀書會` | `2026-11-20` | `本週 W47`，日期顯示 `11/20` |
| `訂場地` | `2026-12-11` | `W50`，日期顯示 `12/11` |
| `寄成果報告` | `2026-12-18` | 超出這 4 週，不列出 |

只有這些任務時，`下週 W48` 與 `W49` 都會寫 `這週沒有任務`。

### 完成與過期的判斷

核取方塊是 `[x]`、`[X]`，或有完成日期標記時算完成，與 [任務日期](#任務日期) 的規則相同。已完成任務顯示打勾與灰字，留在對應的週。

過期任務要有核取方塊、還沒完成，而且有預計日期；預計日期套用週六規則後，那週的星期一比今天這週的星期一早，才算過期。只計算顯示中的專案。日期比今天早、但仍在本週，不算過期。例如今天是 `2026-11-20`，排在 `2026-11-16` 的未完成任務仍留在 `本週 W47`，使用一般文字。4 個週區塊都是本週或未來，過期的紅字只出現在 `之前還沒做`。

### 打勾與移動日期

每行直接放操作控制，不會打開週浮窗。每行都有核取方塊，只有本身有核取方塊且不是重複任務的行才能勾選，編輯限制與週浮窗相同。重複任務的核取方塊不能按，提示是 `重複任務請在筆記裡勾選`。沒有核取方塊的日期文字不能勾選。

勾選會標成完成並寫入今天的完成日期，取消勾選會移除完成日期標記。只有還沒完成、有核取方塊且有預計日期的任務，才顯示 `◀`、`▶`。按一下把第一個預計日期減少或增加 7 天，保留星期幾。符合條件的重複任務仍可用箭頭移日期；已完成、沒有預計日期或沒有核取方塊的行都沒有箭頭。

移動成功後，仍在這 4 週內時，任務直接出現在新的一週，不跳提示。移出範圍時有兩種提示，`<M/D>` 會換成新日期：

- 移到本週之前：`已移到 <M/D>，在「之前還沒做」裡`。例如把 `2026-11-16` 往前移一週，會顯示 `已移到 11/9，在「之前還沒做」裡`。
- 移到第 4 週之後：`已移到 <M/D>，超出這 4 週`。例如把 `2026-12-11` 往後移一週，會顯示 `已移到 12/18，超出這 4 週`。

修改直接存回筆記，寫入前的行內容檢查與週浮窗相同。儲存時暫停該行的控制。筆記不見時提示 `找不到這則筆記`；行內容改過時提示 `這一行在筆記裡剛被改過，畫面已更新，請再試一次`。儀表板會重新整理，筆記保持不變。

### 之前還沒做

週清單上方的 `之前還沒做（n）` 計算過期任務數量；有 `顯示暫停（n）` 時，放在它下面。每次打開儀表板分頁都先收起，前面是 `▸`。點整列展開成 `▾`，再點一次收起。筆記更新時，展開或收起的狀態與捲動位置會保留。

展開後照儀表板的專案順序分組。同一專案內先依預計日期，再依筆記行序排列。每行是紅字、`M/D` 預計日期、核取方塊與 `排到本週`，這一區沒有 `◀`、`▶`。

按 `排到本週`，會把第一個預計日期改成本週的排程日期。寫星期幾依 `Which day to write`，預設星期五，與週浮窗排進某週相同。這會修改原有日期，不會再加第二個日期。任務會離開這一區，出現在 `本週`。

以今天是 `2026-11-20` 為例，選星期五會寫 `2026-11-20`。選星期六且週六規則關閉時，寫 `2026-11-21`。選星期六且週六規則開啟時，寫這週星期一之前的星期六，也就是 `2026-11-14`，任務仍算進 `本週 W47`。

在這一區勾完成的任務，會留在原位顯示成灰字與打勾，直到收起這一區或重新打開儀表板分頁。按錯了可以在原處取消，任務就會恢復紅字與未完成。數量只算還沒完成的任務。收起且沒有過期任務時，標題整列隱藏；展開時數量變成 0，仍保留 `之前還沒做（0）`，收起後才消失。收起時也會移除這一區已勾完成的任務。

### 筆記、設定與其他控制

點週區塊或 `之前還沒做` 裡的專案名稱，會在儀表板自己的分頁打開筆記。按 Obsidian 的返回就能回到儀表板。電腦與平板仍在右側窗格打開筆記。

手機沒有年視圖、月視圖、Timeline、視圖與期間切換、`顯示已結案`、分類與狀態編輯、圖例、日期警告標記與說明面板。`M`、`T`、`?` 快捷鍵不作用，接外接鍵盤也一樣。不能從手機清單新增任務，或把還沒排日期的任務排進來，這些修改請打開筆記處理。資料夾不存在或沒有專案時，沿用電腦上的提示文字，例如 `找不到專案資料夾：<folder>`。

手機上不讀行事曆、不顯示行程，也不發任何網路請求，即使已經設定行事曆也一樣。指令面板裡沒有 `Project Dashboard: Refresh calendars`。設定頁的 `Calendars` 只顯示標題與 `Calendar events show on a computer or tablet. Add your calendars there.`，沒有行事曆欄位或按鈕。手機上不存取密鑰儲存區。儲存其他設定時，原有行事曆清單保持不變。

## 狀態與分類

暫停專案在兩個視圖都預設隱藏。有暫停專案可顯示時才出現 `顯示暫停（<n>）`。只計算指定資料夾內、沒有被略過且有起訖日的專案。每次掃描都更新數量。顯示後保持原本排序，名稱後有灰色 `⏳ 暫停` 標籤，色條有淡化的分類色斜線紋。

`顯示已結案` 一起控制已完成與取消的專案。這些色條轉成灰階，透明度約 35%。每次打開分頁，這兩個顯示勾選框都回到未勾選。

`編輯分類與狀態` 在兩個視圖都能顯示每列的分類與狀態選單。每次打開分頁時預設關閉。狀態選項是 `🚧 進行中`、`⏳ 暫停`、`✅ 完成`、`❌ 取消`。

改狀態時，會把檔名前 3 個字元內的狀態符號與其後空白換成新符號加一個空白。沒有符號就加在最前面。檔名其他部分、資料夾與手動分類都保留。其他筆記連結依 Obsidian 的「自動更新內部連結」設定更新。已經有目標檔名時不改名，顯示 `已經有同名的筆記，狀態沒有改`。新狀態被勾選框隱藏時，重新掃描後那列與浮窗會消失。

手動分類對應到去掉狀態符號後的完整專案名稱，優先於所有名稱規則。選 `自動（清除覆寫）` 可恢復自動分類。存好顯示 `已更新分類`。失敗則顯示 `分類儲存失敗，請再試一次`，選單恢復實際分類。

## 設定

到「設定 → Project Dashboard」調整，不需要重新建置。

### Project notes

- `Project folder`：vault 內的相對資料夾，預設 `Projects`。頭尾空白與 `/` 會去除，清空會回到 `Projects`。找不到最後採用的資料夾時顯示 `Can't find this folder.`。
- `Projects to skip`：一行一個檔名片段，預設空白。忽略頭尾空白與空行，符合任何片段就略過專案。

### Categories

依專案名稱比對文字，由上往下**第一個符合的規則生效**。長詞要排在包含它的短詞前面，例如 `企業內訓` 放在 `內訓` 前。沒有符合就歸到 `其他`。手動分類優先於這些規則。

每列有文字、分類選單、`Move up`、`Move down` 與 `Delete`。按 `Add a rule` 會新增一列空白規則，分類先用 `其他`。空白規則會保留，填入文字前不參與分類。刪除所有規則後，沒有手動分類的專案都歸到 `其他`。

| 預設規則，依順序排列 | 分類 |
| --- | --- |
| `企業內訓` | `企業內訓` |
| `內訓` | `企業內訓` |
| `線上課程` | `線上課程 / Cohort` |
| `課程` | `線上課程 / Cohort` |
| `出版` | `出版` |
| `教練` | `1-on-1 教練` |
| `諮詢` | `1-on-1 教練` |
| `業配` | `業配 / 合作` |
| `合作` | `業配 / 合作` |
| `生活` | `生活` |

七個分類的名稱與圖表顏色是固定的。設定頁調整比對規則，不能改這些名稱或配色。

### Dates

- `Which day to write`：星期一到星期日，預設星期五。從未排日期任務挑選或新增到某週時使用。
- `Saturday tasks count for next week`：預設關閉。開啟後週六任務算到下一週。同時選星期六時的寫入日期例外，見 [週浮窗與編輯](#週浮窗與編輯)。

### Calendars

`Add a calendar` 新增一個空白列。每列有名稱（`Calendar name`，可用中文）、連結欄、`Color` 顏色選擇與 `Delete`。

連結欄會遮住貼上的文字。貼上、按 Enter 或離開欄位時會檢查。有效連結存好後清空。無效連結不存、清空欄位，並顯示 `This is not a calendar link. It should start with https:// or webcal://.`。空白輸入不做更動。存過的連結不會再填回欄位。

| 欄位提示 | 意思 |
| --- | --- |
| `Paste the calendar link here` | 尚未設定連結 |
| `Link saved. Paste a new link to change it.` | 這台電腦已存好連結 |
| `This computer has no link yet. Paste it here.` | 這台電腦缺少該行事曆的連結 |

`Delete` 移除行事曆並清除外掛替它存的連結。貼上或移除都不會覆寫其他用途的密鑰，不需要自己選擇儲存識別碼。

## 說明面板與版面

點右下角 `?` 或按 `?`、`/` 開關說明面板。第一次打開儀表板時會自動顯示，之後記住你有沒有留下它。

有三個分頁。每次開啟都先選目前視圖的分頁。可以點分頁，或在分頁取得焦點時用方向鍵切換：

- `年視圖`：每一格的意思、需要注意、整列狀態、顏色與欄位。包含紅色超出期限格、警告、暫停斜線紋、已結案灰色與今天欄位的小示範。
- `月視圖`：任務文字、格子底色、General 行事曆名稱標籤與重新讀取、`還沒排` 數字。
- `操作`：編輯、切換視圖與期間、版面操作。

選中的分頁有粗體與色底線。內容太長時在面板內捲動。

專案先依分類優先順序排列，同類裡依開始日期排序。預設分類順序是企業內訓、線上課程、教練、出版、業配合作、生活、其他。點圖例把那類置頂，再點一次取消。拖拉圖例可以改分類順序，同時只能置頂一類。

拖拉專案欄右側可調整寬度。預設 280 像素，範圍是 120–600 像素。年視圖與月視圖共用欄寬。

快捷鍵只在儀表板分頁作用。輸入欄、文字區或選單取得焦點時，`T`、`M`、`?`、`/` 都不觸發。按著 Ctrl、Cmd 或 Alt 也不觸發。剛勾完核取方塊仍可按 Escape 關浮窗。在其他文字欄輸入時不會因此關閉。新增任務的輸入框裡按 Escape，只關閉輸入框。

## 更新與儲存

專案筆記變動後，開著的儀表板會等 400 ms 再更新。新增、刪除、改名或移動 Markdown 筆記時，只要新舊任一路徑直接位於專案資料夾就算相關。其他筆記與子資料夾不觸發掃描。沒有開儀表板時不掃描。

更新會保留捲動位置、篩選、視圖、期間、分類順序、置頂分類與欄寬。只要原格子仍可開啟，就會重新打開同專案同一週的浮窗。原本展開的區塊也保留。未送出的輸入保留，送出過的文字清空。輸入框原本有焦點才會恢復焦點，在筆記裡打字時不會跳到儀表板。

點專案名稱會在右側窗格打開筆記。後續點其他專案會沿用該窗格。右側窗格已關閉時會再開一個。點選單不會開筆記。結束 Obsidian 時留下的儀表板分頁，會隨工作區還原並重新讀取筆記。

設定與手動分類共用 `.obsidian/plugins/project-dashboard/data.json`。設定在最後一次修改後 400 ms 儲存，再更新開著的儀表板。每個設定欄位各自檢查，一個欄位有問題不會丟掉其他設定。改分類會保留設定，改設定會保留分類。使用者填的內容不會存在這個 repository。

設定存檔失敗時顯示 `Your settings couldn't be saved. Please try again.`，並還原上次存好的值。Obsidian Sync 等外部設定載入後，會取代本機還在等候儲存的修改。卸載時會把待存設定存一次，之後不再存檔。

視圖選擇、年視圖模式、說明面板狀態、分類順序、置頂分類與欄寬存在這個 vault 的 Obsidian 本機偏好。讀寫失敗時用預設值，圖表仍可運作。顯示中的年份與月份、顯示及編輯勾選框不會記住。行事曆連結另存密鑰儲存區，讀回的行程不會存檔。
