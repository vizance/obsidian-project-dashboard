在專案根目錄執行 `npm run screenshots:build`。
再執行 `python3 scripts/screenshots/capture.py`（需先安裝 Python Playwright 1.63 與 Chromium）。
完成後，11 張使用虛構資料的截圖會存到 `docs/images/`；圖片依內容裁切，含說明面板、暫停列與停在本週的手機月視圖。年視圖會依全年表格寬度擴大，設定頁可用 `dist/index.html?mode=settings` 預覽，手機月視圖可用 `dist/index.html?mode=phone` 預覽。

停在本週的手機月視圖存為 `phone-month-view.png`，以 390 × 844 像素畫布拍攝，日期固定為 2026-11-20，顯示 2026 年 11 月。拍攝前會量測 390 與 800 像素寬的版面，確認打開時停在 W47、本週欄頭標示 `本週` 並貼著名稱欄右緣、W48 完整可見，以及名稱欄已藏起 `P-日期` 代碼。也會確認名稱欄固定在左邊、直放可左右滑看其他週、寬度夠時整個月完整顯示，以及浮窗沒有超出螢幕。

另用 390 × 360 像素畫布，勾選 `顯示暫停（n）` 後把表格往下捲，量測所有欄頭是否固定在表格頂端、月份控制是否留在上方、本週與名稱欄的欄頭是否蓋在資料列上面，以及儀表板分頁本身是否沒有上下捲動。

最後重新打開 390 × 844 像素的手機月視圖，保留停在本週的位置。圖片從左上角裁切，寬 390 像素，高度取表格捲動範圍與表格內容下緣兩者較小的值，無條件進位，最多 844 像素；手機截圖不擴大畫布高度。
